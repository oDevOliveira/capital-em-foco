Capital em Foco

Landing page institucional para uma empresa fictícia de educação financeira, desenvolvida como projeto de portfólio.







Sobre o projeto

A Capital em Foco é uma empresa fictícia criada para este projeto de portfólio, com foco na comercialização de cursos relacionados a finanças e educação financeira.

O objetivo do projeto foi desenvolver uma landing page moderna, elegante e responsiva, utilizando apenas tecnologias web fundamentais, sem frameworks ou bibliotecas externas.

A página foi projetada para simular um site comercial real, incluindo apresentação da empresa, cursos, planos, depoimentos, perguntas frequentes e chamadas para ação.

Aviso: a Capital em Foco é uma empresa fictícia criada exclusivamente para fins demonstrativos e de portfólio. Os cursos, preços, depoimentos e demais informações apresentados na página são ilustrativos.

Como executar localmente

Como o projeto utiliza apenas HTML, CSS e JavaScript, nenhuma instalação de dependências é necessária.

1. Clone o repositório
git clone https://github.com/SEU-USUARIO/capital-em-foco.git
2. Entre na pasta
cd capital-em-foco
3. Abra o projeto

Você pode simplesmente abrir o arquivo:

index.html

diretamente no navegador.

Ou, se estiver utilizando o VS Code, pode usar uma extensão como Live Server para executar o projeto localmente.

WhatsApp

Os botões de compra dos cursos foram estruturados para direcionar o usuário para o WhatsApp.

Antes de utilizar o projeto em produção, substitua o número de exemplo presente nos links pelo número correto da empresa.

Exemplo:

<a
    href="https://wa.me/SEUNUMERO"
    target="_blank"
    rel="noopener noreferrer"
>
    Quero me inscrever
</a>
